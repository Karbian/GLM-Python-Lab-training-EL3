    Python quick reference

    Read a value

    name = input("Name: ")
count = int(input("Count: "))
price = float(input("Price: "))

    The value’s meaning determines its type. input() gives text. Use direct assignment for a fixed value: target = 10.

    Choose an operator

    PurposePythonExample
    Add / subtract+ / -8 - 3 → 5
    Multiply*8 * 3 → 24
    Divide/8 / 2 → 4.0
    Floor division//8 // 3 → 2
    Remainder%8 % 3 → 2
    Power**3 ** 2 → 9

    Floor division rounds down: -7 // 2 is -4. To find a percentage, use part / whole * 100.

    Compare and decide

    if value < target:
    print("Below")
elif value == target:
    print("Equal")
else:
    print("Above")

    = stores. == compares. <= and >= include equality. != means not equal.

    Build a running total

    total = 0
for turn in range(3):
    score = float(input("Score: "))
    total += score
print("Total:", total)

    Initialize the accumulator before the loop. total += score keeps earlier values and adds the next one.

    Protect a division

    if people > 0:
    share = total / people
    print("Share:", share)
else:
    print("Enter people above zero.")

    Check the denominator before dividing. Rounding a zero denominator does not fix division by zero.
